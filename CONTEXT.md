# Roundnet Training Gamification

A mobile-first PWA for a closed, invite-only group of 10–15 roundnet players to log training sessions, track skill progression per category, and earn XP and levels as gamification motivation. All player data (sessions, levels, XP) is visible to all Players in the group.

## Language

**Player**:
A registered user of the app, identified by email/password and an optional nickname. Joins via invite link/code generated by an Admin.
_Avoid_: user, athlete, member

**Admin**:
A Player with the ability to generate invite links/codes to allow new Players to register. No other special permissions at launch.
_Avoid_: owner, superuser, moderator

**Invite**:
A one-time or reusable code/link generated by an Admin that allows a new Player to register.
_Avoid_: token, signup link

**Session**:
A single block of training time logged by a Player on a specific date (defaults to today, editable), containing one or more Session Entries. No start/end timestamps — duration is captured per Session Entry.
_Avoid_: workout, training, practice

**Session Entry**:
A record of one Exercise performed within a Session, capturing volume and a quality score.
_Avoid_: log entry, drill log, activity

**Exercise**:
A named, reusable training activity from the shared Exercise Library, belonging to exactly one Category. Created by a Player; editable only by its creator.
_Avoid_: drill, activity, workout type

**Exercise Library**:
The shared, collectively curated pool of all Exercises available to all Players.
_Avoid_: drill catalog, exercise database

**Category**:
A skill domain that groups Exercises. At launch: Hitting, Serving, Reaction, Setting, Defence. Stored as data, not hardcoded.
_Avoid_: skill type, tag, discipline

**XP (Experience Points)**:
Points earned from Session Entries, calculated as `duration_minutes × quality_multiplier`. Feed into both General Level and Category Level simultaneously.
_Avoid_: points, score

**Quality Score**:
A 1–5 self-assessment of how well a Session Entry went. Maps to XP multipliers: 1→0.5, 2→0.75, 3→1.0, 4→1.25, 5→1.5.
_Avoid_: rating, performance score

**General Level**:
A Player's overall progression level (1–100), derived from cumulative XP across all Categories.
_Avoid_: total level, main level, rank

**Category Level**:
A Player's progression level within a specific Category, derived from XP earned from Exercises in that Category only. Uses the same level curve as General Level.
_Avoid_: skill level, category rank

## Relationships

- A **Player** logs one or more **Sessions**
- A **Session** contains one or more **Session Entries**
- Each **Session Entry** references one **Exercise** from the **Exercise Library**
- Each **Exercise** belongs to exactly one **Category**
- Each **Session Entry** earns **XP** that feeds into the **Player**'s **General Level** and the **Category Level** for that Entry's **Category**

## XP & Level Curve

- XP per entry: `duration_minutes × quality_multiplier`
- Level curve: exponential, tuned so that level 10 ≈ 1 week of regular training (3–4 sessions, ~45 min, medium quality), level 20 ≈ 3 weeks, level 100 ≈ 2 years
- Approximate cumulative XP thresholds: L10=180, L20=540, L50=15,000, L100=200,000

## Example dialogue

> **Dev:** "When a **Player** logs a **Session Entry** for a serving drill, where does the **XP** go?"
> **Domain expert:** "It goes to both their **General Level** and their Serving **Category Level** — the same XP, applied to both. You don't split it."

> **Dev:** "Can I edit an **Exercise** someone else added to the **Exercise Library**?"
> **Domain expert:** "No — you can only edit **Exercises** you created. You can use any Exercise, but only its creator can modify it."
